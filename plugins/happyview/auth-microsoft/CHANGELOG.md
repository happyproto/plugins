## [1.0.0](https://github.com/happyproto/plugins/releases/tag/happyview-auth-microsoft-v1.0.0) (2026-10-07)

- **First release on HappyView v3's plugin API.** Personal Microsoft account sign-in over OAuth 2.0, with refreshable tokens and the user ID and display name read from Microsoft Graph. Built for v3 only; v2 instances keep installing the Microsoft plugin from the old repository.

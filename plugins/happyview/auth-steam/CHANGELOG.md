## [1.0.0](https://github.com/happyproto/plugins/releases/tag/happyview-auth-steam-v1.0.0) (2026-10-07)

- **First release on HappyView v3's plugin API.** Steam sign-in over OpenID 2.0, with every callback verified against Steam before the link is accepted, and profiles (persona name, profile URL, avatar) read from the Steam Web API. Built for v3 only; v2 instances keep installing the Steam plugin from the old repository.

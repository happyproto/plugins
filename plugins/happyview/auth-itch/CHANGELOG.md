## [1.0.0](https://github.com/happyproto/plugins/releases/tag/happyview-auth-itch-v1.0.0) (2026-10-07)

- **First release on HappyView v3's plugin API.** itch.io sign-in over OAuth 2.0 with the `profile:me` scope, and profiles (user ID, display name, profile URL, cover image) read from itch.io's `/me` endpoint. Built for v3 only; v2 instances keep installing the itch.io plugin from the old repository.

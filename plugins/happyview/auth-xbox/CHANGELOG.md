## [1.0.0](https://github.com/happyproto/plugins/releases/tag/happyview-auth-xbox-v1.0.0) (2026-10-07)

- **First release on HappyView v3's plugin API.** Xbox sign-in through Microsoft OAuth 2.0, with refreshable tokens and profiles (XUID, gamertag, gamerpic) read through Xbox Live's user and XSTS token exchanges. Built for v3 only; v2 instances keep installing the Xbox plugin from the old repository.

## [1.0.0 (2026-10-07)](https://github.com/happyproto/plugins/releases/tag/happyview-linked-repos-v1.0.0)

- **First release on HappyView v3's plugin API.** Ships `happyview.linked_repos` as a standalone library plugin: `list()` for the grants it can use, and `get(did)` for a handle that creates, puts and deletes records, uploads blobs, and makes XRPC calls through a linked repo.

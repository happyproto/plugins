## [1.0.0](https://github.com/happyproto/plugins/releases/tag/happyview-http-v1.0.0) (2026-10-07)

- **First release on HappyView v3's plugin API.** Ships `get`, `post`, `put`, `patch`, `delete` and `head`, each returning `{status, body, headers}` with header names lower-cased. Built for v3 only; v2 instances can't install it.
